# Queue in C++ STL
Last Updated : 11 May, 2026
- 
- 
- 

A queue is a [container adapter](https://www.geeksforgeeks.org/cpp/container-adapter-in-cpp/) that stores elements in FIFO (First In, First Out) order. It allows elements to be inserted from the back and removed from the front, ensuring the first inserted element is removed first.

- Supports efficient insertion and deletion operations 
- Widely used in scheduling, buffering, and task management systems![dequeue_operation_in_queue_1](https://media.geeksforgeeks.org/wp-content/uploads/20250930145226252614/dequeue_operation_in_queue_1.webp)Queue in C++
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main()
{
    queue&lt;int&gt; q;
    q.push(10);
    q.push(5);

    // Accessing the front and back elements
    cout &lt;&lt; &quot;Front element: &quot; &lt;&lt; q.front() &lt;&lt; endl;
    cout &lt;&lt; &quot;Back element: &quot; &lt;&lt; q.back() &lt;&lt; endl;

    // Removing an element from the front
    q.pop();

    cout &lt;&lt; &quot;Front element after pop: &quot; &lt;&lt; q.front() &lt;&lt; endl;
    return 0;
}

**Output**Front element: 10
Back element: 5
Front element after pop: 5

## Syntax


Queue is defined as the std::queue class template inside &lt;queue&gt; header file.


queue&lt;T&gt; q;


where,

- ****T:**** DataType of elements in the queue.
- ****q:**** Name assigned to the queue.
## Basic Operations


Here are the basic operations that can be performed on a queue:

### Inserting Elements

- New elements can only be inserted at the back of the queue using [push()](https://www.geeksforgeeks.org/cpp/queue-push-and-queue-pop-in-cpp-stl/) function. 
- The process of inserting elements in a queue is also called enqueue.
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main(){
    queue&lt;int&gt; q;

    // Pushing elements into the queue
    q.push(3);
    q.push(4);
    q.push(5);

    return 0;
}


### Accessing Elements


Only the front and back elements of the queue can be accessed by using [front()](https://www.geeksforgeeks.org/cpp/queuefront-queueback-c-stl/) and [back()](https://www.geeksforgeeks.org/cpp/queuefront-queueback-c-stl/) functions respectively. 

            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main()
{
    queue&lt;int&gt; q;
    q.push(3);
    q.push(4);
    q.push(5);

    // Accessing the front and back elements
    cout &lt;&lt; q.front() &lt;&lt; endl;
    cout &lt;&lt; q.back();
    
    return 0;
}

**Output**3
5
### Deleting Elements

- Elements can only be deleted from the front of the queue using the [pop()](https://www.geeksforgeeks.org/cpp/queue-push-and-queue-pop-in-cpp-stl/) function. 
- The process of deleting elements from a queue is also called dequeue.
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main(){
    queue&lt;int&gt; q;
    q.push(3);
    q.push(4);
    q.push(5);

    // Deleting elements from the front of the queue
    q.pop();

    while (!q.empty()){
        cout &lt;&lt; q.front() &lt;&lt; &quot; &quot;;
        q.pop();
    }
    return 0;
}

**Output**4 5 

****Note:**** In a queue, elements can only be inserted at the back and removed from the front. It does not provide access to middle elements, so deleting an element from the middle is not directly possible.

### empty()

- This checks whether the queue is empty.
-  It returns true if the queue has no elements; otherwise, it returns false.
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main(){

    queue&lt;int&gt; q;
    if (q.empty()){
        cout &lt;&lt; &quot;Queue is empty &quot; &lt;&lt; endl;
    }
    q.push(100);
    if (!q.empty()){
        cout &lt;&lt; &quot;Queue is not empty. Front element: &quot; &lt;&lt; q.front() &lt;&lt; endl;
    }
    return 0;
}

**Output**Queue is empty 
Queue is not empty. Front element: 100

### Size of queue

- The size() function in a queue returns the number of elements currently in the queue.
- It helps to determine how many items are stored without modifying the queue.
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main()
{

    queue&lt;int&gt; q;
    q.push(10);
    q.push(5);
    cout &lt;&lt; &quot;Size of queue: &quot; &lt;&lt; q.size() &lt;&lt; endl;
    q.pop();
    cout &lt;&lt; &quot;Size of queue: &quot; &lt;&lt; q.size() &lt;&lt; endl;
    return 0;
}

**Output**Size of queue: 2
Size of queue: 1

## Pseudo Traversal

- Since only the front and back element can be accessed in a queue, we cannot directly traverse it. 
- On the other hand, we can create a copy of the queue, access the front element, and then delete it, and continue this process until the copied queue is empty. This way, we can effectively traverse all the elements of the queue.
            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main(){
    queue&lt;int&gt; q;
    q.push(3);
    q.push(4);
    q.push(5);

    // Create a copy
    queue&lt;int&gt; temp(q);

    while (!temp.empty())
    {
        cout &lt;&lt; temp.front() &lt;&lt; &quot; &quot;;
        temp.pop();
    }
    return 0;
}
