# Set in C++ STL
Last Updated : 9 Apr, 2026
- 
- 
- 

A Set is a container which stores unique elements in some sorted order. It is an implementation of a Self-Balancing Binary Search Tree, specifically a [Red-Black Tree](https://www.geeksforgeeks.org/dsa/introduction-to-red-black-tree/) which ensures, 

- Search, insert, and delete in O(log n) time.
- Does not allow duplicates.
- Elements are always sorted in ascending order by default. You can also choose your own way of ordering them using a custom rule (comparator).
- Compared to[ unordered_set,](https://www.geeksforgeeks.org/cpp/unordered_set-in-cpp-stl/) the time taken to search, insert, and delete an higher, but we get elements in sorted order and also support additional functions like [upper_bound() ](https://www.geeksforgeeks.org/cpp/upper_bound-in-cpp/)and [lower_bound()](https://www.geeksforgeeks.org/cpp/lower_bound-in-cpp/).

Let us take a look at an example to create a set and traverse it.

            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
using namespace std;

int main() {

    // Creating an empty set
    set&lt;int&gt; s1;

    // Initialize set with list 
    set&lt;int&gt; s2 = {1, 2, 3, 2, 1}; 

    // Traversing the set
    for (auto&amp; x : s2)
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    return 0;
}

**Output**1 2 3 

## Syntax


The set[ container](https://www.geeksforgeeks.org/cpp/containers-cpp-stl/) is defined as ****std::set**** class template inside ****&lt;set&gt; ****header file.


set&lt;T&gt; s;


where,

- ****T:**** Data type of elements in the set.
- ****s:**** Name assigned to the set.
## Basic Operations


Basic operations on set containers are shown below:

### 1. Inserting Elements

- The insert() operation adds a new element to the set only if it not already present.
- If the element already exists, insert() does nothing (since duplicates are not allowed in set).
            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
using namespace std;

int main() {
    // Initialize set with values
    set&lt;int&gt; s = {2, 3};

    // Inserting an element
    s.insert(1);

    // Traversing the set
    for (auto x : s)
        cout &lt;&lt; x &lt;&lt; endl;

    return 0;
}

**Output**1
2
3

###  2. Searching Elements

- The find() function is used to check whether an element exists. It returns an iterator to the element if found, else returns end() if the element is not found.
- The count() function can also be used to check existence, returns 1 if the element is present, 0 otherwise.
            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
using namespace std;

int main() {
    set&lt;int&gt; s = {1, 2, 3};

    // Accessing elements using find()
    auto it = s.find(1);
    if (it != s.end())
        cout &lt;&lt; &quot;Element found: &quot; &lt;&lt; *it &lt;&lt; endl;

    // Accessing elements using count()
    if (s.count(2))
        cout &lt;&lt; &quot;2 exists in the set&quot; &lt;&lt; endl;

    // Accessing all elements by traversal
    cout &lt;&lt; &quot;All elements: &quot;;
    for (auto x : s)
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    return 0;
}

**Output**Element found: 1
2 exists in the set
All elements: 1 2 3 

### 3. Traversing 

- Loops (like range-based for loop or iterators) can be used to traverse all elements in a set.
- The traversal visits elements in sorted order (by default ascending, or according to a custom comparator).
            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
using namespace std;

int main() {
    set&lt;int&gt; s = {1, 2, 3};

    // Traversing using iterators
    for (auto it = s.begin(); it != s.end(); ++it)
        cout &lt;&lt; *it &lt;&lt; endl;  

    return 0;
}

**Output**1
2
3

### 4. Deleting Elements 


To delete an element from a set, use erase(), it removes the element if it exists, else does nothing.

            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
using namespace std;

int main() {
    set&lt;int&gt; s = {1, 2, 3, 4};

    // Deleting by value
    s.erase(2);

    // Deleting by iterator
    s.erase(s.begin());

    // Traversing the set
    for (auto i : s)
        cout &lt;&lt; i &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    return 0;
}

**Output**3 4
