# Containers in C++ STL
Last Updated : 30 May, 2026
- 
- 
- 

The Standard Template Library (STL) provides built-in implementations of commonly used data structures known as containers. A container is an object that stores and manages a collection of elements, making it easier to organize and manipulate data efficiently.

- Provide ready-to-use implementations of commonly used data structures, reducing development time
- Support efficient storage, retrieval, insertion, and deletion of elements through built-in member functions
- Implemented as class templates, allowing the same container to work with different data types
## Common Operations on STL Containers


Most STL containers support a common set of operations for managing and accessing elements.
OperationDescriptioninsert()Adds an element to the containererase()Removes an element from the containersize()Returns the number of elements in the containerempty()Checks whether the container is emptyclear()Removes all elements from the containerbegin()Returns an iterator to the first elementend()Returns an iterator to the position after the last element
## Types of Containers in C++ STL


STL containers are broadly classified into four categories based on how they store and organize elements.

### 1. Sequence Containers


Sequence containers implement linear data structures in which the elements can be accessed sequentially. Following are the sequence containers in C++ STL:

Description


[****Array****](https://www.geeksforgeeks.org/cpp/array-class-c/)


Container that wraps over fixed size static array.


[****Vector****](https://www.geeksforgeeks.org/cpp/vector-in-cpp-stl/)


Automatically resizable dynamic array.


[****Deque****](https://www.geeksforgeeks.org/cpp/deque-cpp-stl/)


Dynamic array of fixed-size arrays that allows fast insertions and deletions at both ends.


[****List****](https://www.geeksforgeeks.org/cpp/list-cpp-stl/)


Implementation of Doubly Linked List data structure.


[****Forward List****](https://www.geeksforgeeks.org/cpp/forward-list-c-set-1-introduction-important-functions/)


Implementation of Singly Linked List data structure.

### 2. Associative Containers


Associative containers store data in some sorted order. It provides fast search, insert and delete in O(log n) time by using balanced trees like Red Black Trees. 


Container Name


Description


[****Set****](https://www.geeksforgeeks.org/cpp/set-in-cpp-stl/)


Collection of unique elements sorted on the basis of their values.


[****Map****](https://www.geeksforgeeks.org/cpp/map-associative-containers-the-c-standard-template-library-stl/)


Collection of key-value pairs sorted on the basis of the keys where no two pairs have same keys.


[****Multiset****](https://www.geeksforgeeks.org/cpp/multiset-in-cpp-stl/)


Collection of elements sorted on the basis of their values but allows multiple copies of values.


[****Multimap****](https://www.geeksforgeeks.org/cpp/multimap-associative-containers-the-c-standard-template-library-stl/)


Collection of key-value pairs sorted on the basis of the keys where multiple pairs can have same keys.

### 3. Unordered Associative Containers


Unordered associative containers implement unsorted hashed data structures that can be quickly searched (O(1) amortized, O(n) worst-case complexity).


Container Name


Description


[****Unordered Set****](https://www.geeksforgeeks.org/cpp/unordered_set-in-cpp-stl/)


Collection of unique elements hashed by their values.


[****Unordered Map****](https://www.geeksforgeeks.org/cpp/unordered_map-in-cpp-stl/)


Collection of key-value pairs that are hashed by their keys where no two pairs have same keys.


[****Unordered Multiset****](https://www.geeksforgeeks.org/cpp/cpp-unordered_multiset/)


Collection of elements hashed by their values and allows multiple copies of values.


[****Unordered Multimap****](https://www.geeksforgeeks.org/cpp/unordered_multimap-and-its-application/)


Collection of key-value pairs that are hashed by their keys where multiple pairs can have same keys.

### 4. Container Adapters


Container adapters provide a different interface for other containers. They adapt the behavior of underlying containers to fit specific use cases.
