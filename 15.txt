## 1. Array


In C++, there are mainly two types of arrays.  

- [Array](https://www.geeksforgeeks.org/cpp/cpp-arrays/): Fixed-size and ideal when the number of elements is known.
- [Vector](https://www.geeksforgeeks.org/cpp/vector-in-cpp-stl/): Dynamic in nature and can grow or shrink as needed. It is part of the C++ Standard Template Library (STL), suitable when the number of elements varies.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{
    // Array example
    int arr[] = {10, 20, 30, 40, 50};
    
    int n = sizeof(arr) / sizeof(arr[0]);
    cout &lt;&lt; &quot;Array elements: &quot;;
    for (int i = 0; i &lt; n; i++)
        cout &lt;&lt; arr[i] &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // Vector Example
    vector&lt;int&gt; list;
    
    list.push_back(10);
    list.push_back(20);
    list.push_back(30);
    cout &lt;&lt; &quot;Vector elements: &quot;;
    for (int i = 0; i &lt; list.size(); i++)
        cout &lt;&lt; list[i] &lt;&lt; &quot; &quot;;

    return 0;
}


**Output**Array elements: 10 20 30 40 50 
Vector elements: 10 20 30

## 2. Searching Algorithms


Searching algorithms help locate an element in data structures like arrays or vectors. C++ provides both linear search and binary search (using functions like std::find and std::binary_search from the &lt;algorithm&gt; library).

            C++

    #include &lt;algorithm&gt;
#include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {
    vector&lt;int&gt; vec = {2, 4, 6, 6, 8, 10};
    int key = 6;

    // Linear search (works on unsorted too)
    bool found = (find(vec.begin(), vec.end(), key) != vec.end());
    cout &lt;&lt; &quot;Found (linear): &quot; &lt;&lt; found &lt;&lt; &quot;\n&quot;;

    // Binary search (requires sorted)
    bool binaryFound = binary_search(vec.begin(), vec.end(), key);
    cout &lt;&lt; &quot;Found (binary): &quot; &lt;&lt; binaryFound &lt;&lt; &quot;\n&quot;;

    // lower_bound: first position not less than key (i.e. first ≥ key)
    int firstIndex = lower_bound(vec.begin(), vec.end(), key) - vec.begin();
    cout &lt;&lt; &quot;First ≥ key at index: &quot; &lt;&lt; firstIndex &lt;&lt; &quot;\n&quot;;

    // upper_bound: first position greater than key
    int afterIndex = upper_bound(vec.begin(), vec.end(), key) - vec.begin();
    cout &lt;&lt; &quot;First &gt; key at index: &quot; &lt;&lt; afterIndex &lt;&lt; &quot;\n&quot;;

    return 0;
}


**Output**Found (linear): 1
Found (binary): 1
First ≥ key at index: 2
First &gt; key at index: 4

## 3. Sorting Algorithms


Sorting arranges elements in ascending or descending order. C++ provides built-in sorting using std::sort() from the &lt;algorithm&gt; library, but you can also implement algorithms like Bubble Sort, QuickSort, and MergeSort.

            C++

    #include &lt;algorithm&gt;
#include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{
    // Array example
    int nums[] = {5, 3, 8, 1};

    int n = sizeof(nums) / sizeof(nums[0]);
    sort(nums, nums + n);
    cout &lt;&lt; &quot;Sorted array: &quot;;
    for (int i = 0; i &lt; n; i++)
        cout &lt;&lt; nums[i] &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // Vector example
    vector&lt;int&gt; list = {5, 3, 8, 1};

    sort(list.begin(), list.end());
    cout &lt;&lt; &quot;Sorted vector: &quot;;
    for (int num : list)
        cout &lt;&lt; num &lt;&lt; &quot; &quot;;

    return 0;
}


**Output**Sorted array: 1 3 5 8 
Sorted vector: 1 3 5 8

## 5. Set


A Set in C++ is a collection that does not allow duplicate elements. Implementations include unordered_set, set, and multiset.

- [Unordered_set](https://www.geeksforgeeks.org/cpp/unordered_set-in-cpp-stl/): Implements hashing where elements are stored without any specific order. Provides fast search, insert, and delete operations.
- [Set](https://www.geeksforgeeks.org/cpp/set-in-cpp-stl/): Implements a self-balancing binary search tree (usually Red-Black Tree). Maintains elements in sorted order and allows moderate time for insertion, search, and deletion.
- [Multiset](https://www.geeksforgeeks.org/cpp/multiset-in-cpp-stl/): Similar to set but allows duplicate elements.
            C++

    #include &lt;iostream&gt;
#include &lt;set&gt;
#include &lt;unordered_set&gt;
using namespace std;

int main()
{
    // set (sorted, unique elements)
    set&lt;int&gt; s{10, 20, 20, 30};
    cout &lt;&lt; &quot;set: &quot;;
    for (auto &amp;x : s)
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // unordered_set (no order, unique elements)
    unordered_set&lt;int&gt; us{10, 20, 20, 30};
    cout &lt;&lt; &quot;unordered_set: &quot;;
    for (auto &amp;x : us)
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // multiset (sorted, allows duplicates)
    multiset&lt;int&gt; ms{10, 20, 20, 30};
    cout &lt;&lt; &quot;multiset: &quot;;
    for (auto &amp;x : ms)
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    return 0;
}


**Output**set: 10 20 30 
unordered_set: 30 20 10 
multiset: 10 20 20 30

## 6. Map


A Map in C++ is a collection of key-value pairs that associates unique keys with values. Implementations include unordered_map, map, and multimap.

- [Map](https://www.geeksforgeeks.org/cpp/map-associative-containers-the-c-standard-template-library-stl/): Implements a self-balancing binary search tree (usually Red-Black Tree). Maintains elements in sorted order by key.
- [Unordered Map](https://www.geeksforgeeks.org/cpp/unordered_map-in-cpp-stl/): Implements hashing where elements are stored without any specific order. Provides fast average-case search, insertion, and deletion operations .
- [Multimap](https://www.geeksforgeeks.org/cpp/multimap-associative-containers-the-c-standard-template-library-stl/): Similar to map, but allows duplicate keys and maintains elements in sorted order by key.
            C++

    #include &lt;iostream&gt;
#include &lt;map&gt;
#include &lt;unordered_map&gt;
using namespace std;

int main()
{
    // map (sorted by keys)
    map&lt;int, string&gt; m{{1, &quot;apple&quot;}, {3, &quot;banana&quot;}, {2, &quot;cherry&quot;}};
    cout &lt;&lt; &quot;map: &quot;;
    for (auto &amp;p : m)
        cout &lt;&lt; p.first &lt;&lt; &quot;-&gt;&quot; &lt;&lt; p.second &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // unordered_map (no specific order)
    unordered_map&lt;int, string&gt; um{{1, &quot;red&quot;}, {2, &quot;green&quot;}, {3, &quot;blue&quot;}};
    cout &lt;&lt; &quot;unordered_map: &quot;;
    for (auto &amp;p : um)
        cout &lt;&lt; p.first &lt;&lt; &quot;-&gt;&quot; &lt;&lt; p.second &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    // multimap (allows duplicate keys)
    multimap&lt;int, string&gt; mm{{1, &quot;cat&quot;}, {1, &quot;dog&quot;}, {2, &quot;bird&quot;}};
    cout &lt;&lt; &quot;multimap: &quot;;
    for (auto &amp;p : mm)
        cout &lt;&lt; p.first &lt;&lt; &quot;-&gt;&quot; &lt;&lt; p.second &lt;&lt; &quot; &quot;;
    cout &lt;&lt; endl;

    return 0;
}


**Output**map: 1-&gt;apple 2-&gt;cherry 3-&gt;banana 
unordered_map: 3-&gt;blue 2-&gt;green 1-&gt;red 
multimap: 1-&gt;cat 1-&gt;dog 2-&gt;bird

## 7. Recursion


Recursion is a technique where a method calls itself to solve smaller subproblems.

            C++

    #include &lt;iostream&gt;
using namespace std;

int fact(int n)
{
    if (n == 0)
        return 1;
    return n * fact(n - 1);
}

int main()
{
    cout &lt;&lt; fact(5); 
    return 0;
}

## 8. Queue


A queue follows the FIFO (First In First Out) principle. C++ provides the queue container in the &lt;queue&gt; header, and you can also use priority queues using [priority_queue](https://www.geeksforgeeks.org/cpp/priority-queue-in-cpp-stl/).

            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
using namespace std;

int main()
{
    queue&lt;int&gt; q;

    // Add elements to the queue
    q.push(10);
    q.push(20);
    q.push(30);

    // Remove elements from the queue (FIFO)
    while (!q.empty())
    {
        cout &lt;&lt; q.front() &lt;&lt; &quot; &quot;;
        q.pop();
    }

    return 0;
}


**Output**10 20 30

## 9. Stack


A stack follows the LIFO (Last In First Out) principle. In C++, you can use the [stack ](https://www.geeksforgeeks.org/cpp/stack-in-cpp-stl/)container provided in the &lt;stack&gt; header. It is a simple and efficient implementation for typical stack operations. For more flexibility, you can also use vector or deque as underlying containers, since stack by default uses deque.

            C++

    #include &lt;iostream&gt;
#include &lt;stack&gt;
using namespace std;

int main()
{
    stack&lt;string&gt; st;

    // Push elements onto the stack
    st.push(&quot;g&quot;);
    st.push(&quot;f&quot;);
    st.push(&quot;h&quot;);

    // Print the initial stack by popping elements
    cout &lt;&lt; &quot;Stack Content (top to bottom): &quot;;
    while (!st.empty())
    {
        cout &lt;&lt; st.top() &lt;&lt; &quot; &quot;;
        st.pop();
    }

    return 0;
}


**Output**Stack Content (top to bottom): h f g

## 10. Linked List


A Linked List is a linear data structure where each element (node) contains data and a reference to the next node.

            C++

    #include &lt;iostream&gt;
using namespace std;

class Node
{
  public:
    int data;
    Node *next;

    Node(int d)
    {
        data = d;
        next = nullptr;
    }
};

int main()
{
    // Create nodes
    Node *head = new Node(10);
    head-&gt;next = new Node(20);
    head-&gt;next-&gt;next = new Node(30);

    // Traverse and print the linked list
    Node *temp = head;
    while (temp != nullptr)
    {
        cout &lt;&lt; temp-&gt;data &lt;&lt; &quot; &quot;;
        temp = temp-&gt;next;
    }

    return 0;
}


**Output**10 20 30

## 11. Tree


A[ Tree](https://www.geeksforgeeks.org/dsa/tree-data-structure/) is a hierarchical data structure with nodes connected by edges. The top node is the root.

            C++

    #include &lt;iostream&gt;
using namespace std;

class Node
{
  public:
    int data;
    Node *left;
    Node *right;

    Node(int val)
    {
        data = val;
        left = nullptr;
        right = nullptr;
    }
};

// Inorder traversal
void inorder(Node *root)
{
    if (root == nullptr)
        return;
    inorder(root-&gt;left);
    cout &lt;&lt; root-&gt;data &lt;&lt; &quot; &quot;;
    inorder(root-&gt;right);
}

int main()
{
    // Create tree nodes
    Node *root = new Node(1);
    root-&gt;left = new Node(2);
    root-&gt;right = new Node(3);
    root-&gt;left-&gt;left = new Node(4);

    // Print inorder traversal
    inorder(root);

    return 0;
}


**Output**4 2 1 3

## 12. Heap


A Heap is a special tree-based structure that satisfies the heap property (Min-Heap or Max-Heap). In C++, we can use [priority_queue](https://www.geeksforgeeks.org/cpp/priority-queue-in-cpp-stl/).

            C++

    #include &lt;iostream&gt;
#include &lt;queue&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{
    priority_queue&lt;int, vector&lt;int&gt;, greater&lt;int&gt;&gt; pq; // Min-Heap

    pq.push(10);
    pq.push(30);
    pq.push(20);

    cout &lt;&lt; &quot;Min-Heap elements: &quot;;
    while (!pq.empty())
    {
        cout &lt;&lt; pq.top() &lt;&lt; &quot; &quot;; 
        pq.pop();
    }

    return 0;
}


**Output**Min-Heap elements: 10 20 30

## 13. Graphs


A Graph consists of nodes (vertices) connected by edges. In C++, it can be represented using an [adjacency list](https://www.geeksforgeeks.org/cpp/cpp-program-to-implement-adjacency-list/) with vector or list.

            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

// Function to add an edge between two vertices
void addEdge(vector&lt;vector&lt;int&gt;&gt; &amp;adj, int i, int j)
{
    adj[i].push_back(j);
    adj[j].push_back(i);
}

// Function to display the adjacency list
void displayAdjList(const vector&lt;vector&lt;int&gt;&gt; &amp;adj)
{
    for (int i = 0; i &lt; adj.size(); i++)
    {
        cout &lt;&lt; i &lt;&lt; &quot;: &quot;;
        for (int j : adj[i])
        {
            cout &lt;&lt; j &lt;&lt; &quot; &quot;;
        }
        cout &lt;&lt; endl;
    }
}

int main()
{
    int V = 4;

    // Create an adjacency list with V empty lists
    vector&lt;vector&lt;int&gt;&gt; adj(V);

    // Add edges
    addEdge(adj, 0, 1);
    addEdge(adj, 0, 2);
    addEdge(adj, 1, 2);
    addEdge(adj, 2, 3);

    cout &lt;&lt; &quot;Adjacency List Representation:&quot; &lt;&lt; endl;
    displayAdjList(adj);

    return 0;
}


**Output**Adjacency List Representation:
0: 1 2 
1: 0 2 
2: 0 1 3 
3: 2

## 14. Dynamic Programming (DP)


DP is used when problems have overlapping subproblems and optimal substructure. Example: Fibonacci series using DP.

            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int fib(int n, vector&lt;int&gt; &amp;dp)
{
    if (n &lt;= 1)
        return n;
    if (dp[n] != -1)
        return dp[n];
    return dp[n] = fib(n - 1, dp) + fib(n - 2, dp);
}

int main()
{
    int n = 10;
    vector&lt;int&gt; dp(n + 1, -1);

    cout &lt;&lt; &quot;Fibonacci(&quot; &lt;&lt; n &lt;&lt; &quot;): &quot; &lt;&lt; fib(n, dp) &lt;&lt; endl;

    return 0;
}


**Output**Fibonacci(10): 55
