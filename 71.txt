# Vector in C++ STL
Last Updated : 11 May, 2026
- 
- 
- 

A vector represents a dynamic sized array in the Standard Template Library(STL) that automatically grows when elements are added beyond current capacity.

- A programmer does not have to worry about maintaining the capacity and allocating extra space initially.
- Certain insertions and removals can become slightly costly in terms of time as it internally resizes itself beyond certain predefined limits. If time taken for these operations is super critical, then use of [plain arrays in C++](https://www.geeksforgeeks.org/cpp/cpp-arrays/) should be preferred.
- Vectors support bound checking by using v.at(i) for accessing an element at index i in a vector v. 
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;
int main() {
    
    // Declares an empty vector
    vector&lt;int&gt; v1;
    
    // Declares vector with given size
    // and fills it with a value
    vector&lt;int&gt; v2(3, 5);  
    
    // Print items of v2
    for (int x : v2) {
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    }
    
    cout &lt;&lt; endl;
    
    // Initializes vector using 
    // initializer list.
    vector&lt;int&gt; v3 = {1, 2, 3};  
    
    // Print items of v3
    for (int x : v3) {
        cout &lt;&lt; x &lt;&lt; &quot; &quot;;
    }
    
    return 0;
}

**Output**5 5 5 
1 2 3 
## Declaration and Initialization of a Vector 


A vector is defined as the std::vector class template in the &lt;****vector****&gt; header file.


vector&lt;T&gt; v;


where**** T ****is the data type of elements and ****v ****is the name assigned to the vector.

## Operations in Vector


Vectors in C++ support various useful operations that allow you to add, remove, access, and modify elements dynamically.

### Insert Elements

- [push_back(value):](https://www.geeksforgeeks.org/cpp/vector-push-back-cpp-stl/) Inserts element at the end of the vector efficiently. Takes constant time O(1) on average, so it's very fast.
- [insert(position, value):](https://www.geeksforgeeks.org/cpp/vector-insert-function-in-cpp-stl/) Inserts element at any position (beginning, middle, or end). Takes linear time O(n), as it shifts elements to make space.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {
    vector&lt;char&gt; v = {&#39;a&#39;, &#39;f&#39;, &#39;d&#39;};
  
  	// Inserting &#39;z&#39; at the back
  	v.push_back(&#39;z&#39;);
  
  	// Inserting &#39;c&#39; at index 1
  	v.insert(v.begin() + 1, &#39;c&#39;);

  	for (char i : v)
        cout &lt;&lt; i &lt;&lt; &quot; &quot;;
    return 0;
}

**Output**a c f d z 
### Access elements

- We can access elements in a vector using v[i] for direct access or v.at(i) for bounds-checked access.
- Both return the element at index i, but at(i) throws an exception if i is out of range.
- It takes constant time O(1) on average, so it's very fast.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{
    vector&lt;int&gt; v = {10, 20, 30, 40};
    
    // Accessing using operator[]
    cout &lt;&lt; &quot;Element at index 2 using []: &quot; &lt;&lt; v[2] &lt;&lt; endl;
    
    // Accessing using at()
    cout &lt;&lt; &quot;Element at index 3 using at(): &quot; &lt;&lt; v.at(3) &lt;&lt; endl;
    
    // Uncommenting the next line will throw an 
    // out_of_range exception 
    // cout v.at(10)&lt;&lt;endl;
    return 0;
}

**Output**Element at index 2 using []: 30
Element at index 3 using at(): 40

### Update elements

- To update an element, you simply use its index with the assignment operator, for example v[i]=newValue;
- This replaces the old element at index i with the new value you want.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main()
{

    vector&lt;int&gt; v = {10, 20, 30};
    cout &lt;&lt; &quot;Original value at index 1: &quot; &lt;&lt; v[1] &lt;&lt; endl;

    // Updating the element at index i
    v[1] = 50;

    cout &lt;&lt; &quot;Updated value at index 1: &quot; &lt;&lt; v[1] &lt;&lt; endl;
    return 0;
}

**Output**Original value at index 1: 20
Updated value at index 1: 50

### Find Vector Size


We can find the size(number of elements) of a vector using the size() function, like v.size(). 

            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {
    vector&lt;char&gt; v = {&#39;a&#39;, &#39;c&#39;, &#39;f&#39;, &#39;d&#39;, &#39;z&#39;};

    // Finding size
    cout &lt;&lt; v.size();
  
    return 0;
}

**Output**5
### Traverse Vector

- Traversing a vector means going through each element one by one, usually using a loop.
- We can use a for loop with an index (v[i]), a range-based for loop (for(int x: v)), or iterators.
- It takes linear time O(n) .
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {
    vector&lt;char&gt; v = {&#39;a&#39;, &#39;c&#39;, &#39;f&#39;, &#39;d&#39;, &#39;z&#39;};

    // Range-based loop
  	for (char i : v)
        cout &lt;&lt; i &lt;&lt; &quot; &quot;;
    return 0;
}

**Output**a c f d z 

****Recommendation:****

- Use "for (char &amp;x : v)" when you want to modify the elements of the vector. 
- Use "for (const char &amp;x : v)" for read-only access, as it avoids copying and improves efficiency.
### Delete Elements

- Elements can be deleted from a vector using erase(), which requires an iterator pointing to the element. It takes linear time O(n) because all elements after the erased one need to be shifted.
- To remove the last element efficiently, use pop_back() . It takes constant time O(1) on average, so it's very fast.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
#include &lt;algorithm&gt;
using namespace std;

int main() {
    vector&lt;char&gt; v = {&#39;a&#39;, &#39;c&#39;, &#39;f&#39;, &#39;d&#39;, &#39;z&#39;};

    // Deleting last element &#39;z&#39;
  	v.pop_back();
  
  	// Deleting element &#39;f&#39;
  	v.erase(find(v.begin(), v.end(), &#39;f&#39;));
  	
  	for (int i = 0; i &lt; v.size(); i++) {
        cout &lt;&lt; v[i] &lt;&lt; &quot; &quot;;
    }
    return 0;
}

**Output**a c d 
### Vector is Empty

- To check if the vector is empty we use empty() function. It returns true if the vector has no elements ,and false otherwise. 
- This is useful before accessing or modifying the vector to avoid errors.
            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {

    vector&lt;int&gt;v;
    
    // Check if the vector is empty
    if(v.empty()){
        cout&lt;&lt;&quot;Vector is empty.&quot;&lt;&lt;endl;
    }
    
    // Add an element
    v.push_back(100);
    if(!v.empty()){
        cout&lt;&lt;&quot;Vector is not empty. First element &quot;&lt;&lt;v[0]&lt;&lt;endl;
    }
    return 0;
}

**Output**Vector is empty.
Vector is not empty. First element 100

### Multidimensional Vectors


[Multidimensional vectors](https://www.geeksforgeeks.org/cpp/vector-of-vectors-in-c-stl-with-examples/) are dynamic arrays that can store data in more than one dimension, like tables or grids. They are implemented using vector inside another vector, allowing flexible row-column (2D), or even higher-dimensional structures.


****Syntax to declare a 2D vector:****


vector&lt;vector&lt;int&gt;&gt; matrix;


Below is an example of creating a 2D vector and traversing over it:

            C++

    #include &lt;iostream&gt;
#include &lt;vector&gt;
using namespace std;

int main() {
    // Declaring and Initializing a 2D vector
    vector&lt;vector&lt;int&gt;&gt; matrix = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };

    // Traversing using range-based loop with auto
    for (const auto &amp;row : matrix) {
        for (const auto &amp;val : row) {
            cout &lt;&lt; val &lt;&lt; &quot; &quot;;
        }
        cout&lt;&lt;endl;
    }
    return 0;
}

**Output**1 2 3 
4 5 6 
7 8 9
