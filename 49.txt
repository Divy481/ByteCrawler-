# Decision Making in C++
Last Updated : 25 Apr, 2026
- 
- 
- 

Decision-making is about conditional execution of a part of the code. In C++, the following decision-making statements are used:
![cpp decision making statements](https://media.geeksforgeeks.org/wp-content/uploads/20240115114549/cpp-conditional-statements.webp) 
## if Statement


In C++, the [****if statement****](https://www.geeksforgeeks.org/cpp/c-c-if-statement-with-examples/) is the simplest decision-making statement. It allows the execution of a block of code if the given condition is true. The body of the if statement is executed only if the given condition is true.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int age = 19;
  
  	// Check if age is greater than 18 fo
  	// vote eligiblity
    if (age &gt; 18) {
        cout &lt;&lt; &quot;allowed to vote&quot;;
    }
    return 0;
}

**Output**allowed to vote

Curly braces can be omitted if there is only a single statement inside the if block.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int age = 19;
    if (age &gt; 18)
        cout &lt;&lt; &quot;allowed to vote&quot;;
    return 0;
}

**Output**allowed to vote

## 2. if-else Statement


The [****if else****](https://www.geeksforgeeks.org/cpp/c-c-if-else-statement-with-examples/) is adecision-making statement allows us to make a decision based on the evaluation of a given condition. If the given condition evaluates to true then the code inside the 'if' block is executed and in case the condition is false, the code inside the 'else' block is executed.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int n = 5;

    // Using if-else to determine if the number is positive
    // or non positive
    if (n &gt; 0) {
        cout &lt;&lt; &quot;number is positive.&quot;;
    }
    else {
        cout &lt;&lt; &quot;number is non-positive.&quot;;
    }
    return 0;
}

**Output**number is positive.

## 3. if else if Ladder


The [****if else if Ladder****](https://www.geeksforgeeks.org/cpp/c-c-if-else-if-ladder-with-examples/) statements allow us to include additional situations after the preliminary if condition. The 'else if' condition is checked only if the above condition is not true, and the `else` is the statement that will be executed if none of the above conditions is true. If a condition is true, only its associated block is executed.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int age = 18;

    // if this condition is true child is printed
    if (age &lt; 13) {
        cout &lt;&lt; &quot;child&quot;;
    }
 
    // if above if statement is not true then we check
    // this else if condition if it evaluates to true print
    // growing age
    else if (age &gt;= 1 and age &lt;= 18) {
        cout &lt;&lt; &quot;Growing stage&quot;;
    }

    // if none of above condition is true print adult
    else {
        cout &lt;&lt; &quot;adult&quot;;
    }
    return 0;
}

**Output**Growing stage

## 4. Nested if else


A [nested if-else statement ](https://www.geeksforgeeks.org/cpp/cpp-nested-if-else-statement/)contains an 'if' inside another 'if'. It is used to check multiple conditions, and the block of the if whose condition evaluates to true is executed.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int n = 44;
  
    // to check if n is positive
    if (n &gt; 0) {

        // to check if the positive n is even or odd
        if (n % 2 == 0) {
            cout &lt;&lt; &quot;positive and even number&quot;;
        }
        else {
            cout &lt;&lt; &quot;positive and odd number&quot;;
        }
    }
    // to check if the n is 0
    else if (n == 0) {
        cout &lt;&lt; &quot;the number is zero&quot;;
    }
    // to check if the n is negative
    else {
        cout &lt;&lt; &quot;the number is negative&quot;;
    }
    return 0;
}

**Output**positive and even number

## 5. Switch Statement


In C++, the [****switch statement****](https://www.geeksforgeeks.org/cpp/switch-statement-in-cpp/) is used when multiple situations need to be evaluated primarily based on the value of a variable or an expression. switch statement acts as an alternative to multiple if statements or if-else ladder and has a cleaner structure and it is easy for handling multiple conditions.

            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    char c = &#39;B&#39;;
    switch (c) {
        
    // if the input character is A then print GFG
    case &#39;A&#39;:
        cout &lt;&lt; &quot;GFG&quot;;
        break;

    // if the input character is B then print
    // GeeksforGeeks
    case &#39;B&#39;:
        cout &lt;&lt; &quot;GeeksforGeeks&quot;;
        break;
    default:
        
        // if the input character is invalid then print
        // invalid input
        cout &lt;&lt; &quot;invalid input&quot;;
    }
    return 0;
}

**Output**GeeksforGeeks

## 6. Ternary Operator ( ? : )


The [****conditional operator ****](https://www.geeksforgeeks.org/cpp/cpp-ternary-or-conditional-operator/)is also known as a ****ternary operator****. It is used to write conditional operations provided by C++. The '?' operator first checks the given condition, if the condition is true then the first expression is executed otherwise the second expression is executed. It is an alternative to an if-else condition in C++.

            C++

    expression ? statement_1 : statement_2;


            C++

    #include &lt;iostream&gt;
using namespace std;

int main() {
    int num1 = 10, num2 = 40;
    int max;
  
    // if the condition is true then num1 will be printed
    // else num2 will be printed
    max = (num1 &gt; num2) ? num1 : num2;
    cout &lt;&lt; max;
    return 0;
}
