# Standard Template Library (STL) in C++
Last Updated : 16 May, 2026
- 
- 
- 

STL (Standard Template Library) is a collection of pre-built classes and functions in C++ used for efficient data handling and programming. It provides ready-to-use data structures and algorithms that simplify development.

- Includes containers like vectors, stacks, queues, and maps. 
- Saves time and improves performance using reusable components.
## Components of STL


The components of STL are the features provided by STL in C++ that can be classified into 3 types:
![components_of_stl](https://media.geeksforgeeks.org/wp-content/uploads/20250818102717729926/components_of_stl.webp) 

These components are designed to be efficient, flexible, and reusable, making them an integral part of modern C++ programming. 

## Containers


[Containers](https://www.geeksforgeeks.org/cpp/containers-cpp-stl/) are the data structures used to store objects and data according to the requirement. Each container is implemented as a template class that also contains the methods to perform basic operations on it. Every STL container is defined inside its own header file.


Containers can be further classified into 4 types:

- Sequence Containers :**** ****[Vector](https://www.geeksforgeeks.org/cpp/vector-in-cpp-stl/)****, ****[Deque](https://www.geeksforgeeks.org/cpp/deque-cpp-stl/)****, ****[List](https://www.geeksforgeeks.org/cpp/list-cpp-stl/)****, ****[Forward List](https://www.geeksforgeeks.org/cpp/forward-list-c-set-1-introduction-important-functions/)****, ****[Array](https://www.geeksforgeeks.org/cpp/stdarray-in-cpp/)
- Container Adaptors :**** ****[Stack](https://www.geeksforgeeks.org/cpp/stack-in-cpp-stl/)****, ****[Queue](https://www.geeksforgeeks.org/cpp/queue-cpp-stl/)****, ****[Priority Queue](https://www.geeksforgeeks.org/cpp/priority-queue-in-cpp-stl/)
- Associative Containers :**** ****[Set](https://www.geeksforgeeks.org/cpp/set-in-cpp-stl/)****, ****[Multiset](https://www.geeksforgeeks.org/cpp/multiset-in-cpp-stl/)****, ****[Map](https://www.geeksforgeeks.org/cpp/map-associative-containers-the-c-standard-template-library-stl/)****, ****[Multimap](https://www.geeksforgeeks.org/cpp/multimap-associative-containers-the-c-standard-template-library-stl/)
- Unordered Associative Containers :**** ****[Unordered Set](https://www.geeksforgeeks.org/cpp/unordered_set-in-cpp-stl/)****, ****[Unordered Multiset](https://www.geeksforgeeks.org/cpp/cpp-unordered_multiset/)****, ****[Unordered Map](https://www.geeksforgeeks.org/cpp/cpp-unordered_multiset/)****, ****[Unordered Multimap](https://www.geeksforgeeks.org/cpp/unordered_multimap-and-its-application/)

Instead of writing your own data structures (like linked lists or stacks), STL provides ready-made containers that are: Fast, Reliable, Easy-to-use and Type-Safe (work with any data type using templates).

## Algorithms


[STL algorithms](https://www.geeksforgeeks.org/cpp/c-magicians-stl-algorithms/) offer a wide range of functions to perform common operations on data (mainly containers). These functions implement the most efficient version of the algorithm for tasks such as sorting, searching, modifying and manipulating data in containers, etc. Most STL algorithms are defined in &lt;algorithm&gt; and &lt;numeric&gt;, while some specialized algorithms and utilities are available in other headers like &lt;memory&gt;, &lt;functional&gt;, and &lt;iterator&gt;. Some of the most frequently used algorithms are: 

- [Sort](https://www.geeksforgeeks.org/cpp/sort-algorithms-the-c-standard-template-library-stl/) : Arranges elements in ascending order (default).
- [Binary Search](https://www.geeksforgeeks.org/cpp/binary-search-algorithms-the-c-standard-template-library-stl/) : Checks whether a value exists in a sorted range.
- [Find](https://www.geeksforgeeks.org/cpp/std-find-in-cpp/) : Searches for the first occurrence of a given value.
- [Count](https://www.geeksforgeeks.org/cpp/std-count-cpp-stl/) : Counts how many times a value appears in the given range.
- [Reverse](https://www.geeksforgeeks.org/cpp/stdreverse-in-c/) : Reverses the order of elements in the given range.
- [Accumulate](https://www.geeksforgeeks.org/cpp/accumulate-and-partial_sum-in-c-stl-numeric-header/) : Computes the sum of all elements in the range.
- [Unique](https://www.geeksforgeeks.org/cpp/stdunique-in-cpp/) : Removes consecutive duplicate elements.
- [Lower bound](https://www.geeksforgeeks.org/cpp/lower_bound-in-cpp/) : Returns iterator to the first element ≥ value in a sorted range.
- [Upper bound](https://www.geeksforgeeks.org/cpp/upper_bound-in-cpp/) : Returns iterator to the first element &gt; value in a sorted range.
- [Replace](https://www.geeksforgeeks.org/cpp/stdreplace-stdreplace_if-c/) : Replaces all occurrences of old value with new value in the given range.
## ****Iterators****


[Iterators](https://www.geeksforgeeks.org/cpp/introduction-iterators-c/) are the pointer like objects that are used to point to the memory addresses of STL containers. They are one of the most important components that contributes the most in connecting the STL algorithms with the containers. Iterators are defined inside the ****&lt;iterator&gt; ****header file.
