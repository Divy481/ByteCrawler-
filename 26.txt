# Templates in C++
Last Updated : 9 Apr, 2026
- 
- 
- 

A C++ template is a tool for creating [generic classes](https://www.geeksforgeeks.org/cpp/generics-in-c/) or functions. This allows us to write code that works for any data type without rewriting it for each type. 

- Avoid code duplication by allowing one function or class to work with multiple data types, mainly allowing generic functions and classes.
- Provides type safety unlike void* pointers or macros, and can be specialized for specific data types when needed.
- Form the basis of [STL containers](https://www.geeksforgeeks.org/cpp/containers-cpp-stl/) and [algorithms](https://www.geeksforgeeks.org/cpp/c-magicians-stl-algorithms/) like vector, map, and sort.

****Example: ****Below code demonstrates a generic function that return the maximum among the two passed arguments to the function:

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T&gt; T myMax(T x, T y){
    return (x &gt; y) ? x : y;
}

int main(){

    cout &lt;&lt; &quot;Max of 3 and 7 is: &quot; &lt;&lt; myMax&lt;int&gt;(3, 7) &lt;&lt; endl;
    cout &lt;&lt; &quot;Max of 3.5 and 7.5 is :&quot; &lt;&lt; myMax&lt;double&gt;(3.5, 7.5) &lt;&lt; endl;
    cout &lt;&lt; &quot;Max of &#39;g&#39; and &#39;e&#39; is: &quot; &lt;&lt; myMax&lt;char&gt;(&#39;g&#39;, &#39;e&#39;) &lt;&lt; endl;
    
    return 0;
}

**Output**Max of 3 and 7 is: 7
Max of 3.5 and 7.5 is :7.5
Max of 'g' and 'e' is: g


****Explanation: ****

- "template &lt;typename T&gt;" makes "myMax" a generic function that works with any data type.
- The compiler creates a separate version of myMax for int, double, and char based on how it’s called.
- myMax&lt;int&gt;(3,7), myMax&lt;double&gt;(3.5,7.5), and myMax&lt;char&gt;('g','e') compare values of those types.
- The function returns the larger of the two values using the condition (x &gt; y) ? x : y.![420046719](https://media.geeksforgeeks.org/wp-content/uploads/20250926105944844875/420046719.webp)Compiler creates type-specific functions from a single template automatically.
### Syntax of Templates


Templates are defined using the template keyword and template parameters declared using typename or class.


template &lt;typename A, typename B, ...&gt;entity_definition


typename and class are interchangeable in template declarations.

## Templates can be used to define:

- Function Templates
- Class Templates
- Variable Templates (C++14 onwards)
## Function Templates


In C++, templates allow us to write [****generic****](https://www.geeksforgeeks.org/cpp/generics-in-c/) code for functions that can be used with different data types, and this can be achieved by function templates. 


****Example: ****Maximum of Two Values

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T&gt; T myMax(T x, T y){
    return (x &gt; y) ? x : y;
}

int main(){

    cout &lt;&lt; myMax&lt;int&gt;(3, 7) &lt;&lt; endl;
    cout &lt;&lt; myMax&lt;double&gt;(3.0, 7.0) &lt;&lt; endl;
    cout &lt;&lt; myMax&lt;char&gt;(&#39;g&#39;, &#39;e&#39;);
    return 0;
}

**Output**7
7
g

## Class Templates


Class templates like function templates, are useful when a class defines something that is independent of the data type. It is useful for classes like LinkedList, BinaryTree, Stack, Queue, Array, etc.

            C++

    #include &lt;iostream&gt;
using namespace std;


template &lt;typename T&gt; class Geek{
  public:
    T x;
    T y;

    // Constructor
    Geek(T val1, T val2) : x(val1), y(val2){
    }

    // Method to get values
    void getValues(){
        cout &lt;&lt; x &lt;&lt; &quot; &quot; &lt;&lt; y;
    }
};

int main(){
    Geek&lt;int&gt; intGeek(10, 20);
    Geek&lt;double&gt; doubleGeek(3.14, 6.28);
    intGeek.getValues();
    cout &lt;&lt; endl;
    doubleGeek.getValues();
    return 0;
}

**Output**10 20
3.14 6.28

****Explanation:****

- "template &lt;typename T&gt;" makes "Geek" a generic class that can work with different data types.
- When you write "Geek&lt;int&gt;" or "Geek&lt;double&gt;", the compiler creates a version of the class for that type.
- The constructor stores the passed values into x and y.
- Calling "getValues()" prints the stored values for each template instance.

We can pass more than one data type as arguments to templates.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T1, typename T2, typename T3&gt; class Geek {
  public:
    T1 x;
    T2 y;
    T3 z;

    Geek(T1 val1, T2 val2, T3 val3) : x(val1), y(val2), z(val3){
    }

    void getValues(){
        cout &lt;&lt; x &lt;&lt; &quot; &quot; &lt;&lt; y &lt;&lt; &quot; &quot; &lt;&lt; z;
    }
};

int main(){

    Geek&lt;int, double, string&gt; intDoubleStringGeek(10, 3.14, &quot;Hello&quot;);
    Geek&lt;char, float, bool&gt; charFloatBoolGeek(&#39;A&#39;, 5.67f, true);

    intDoubleStringGeek.getValues();
    cout &lt;&lt; endl;
    charFloatBoolGeek.getValues();
    return 0;
}

**Output**10 3.14 Hello
A 5.67 1
## Template Variables (Since C++ 14)


A template variable is a variable that can work with any type specified when the variable is used, similar to how we use templates for functions or classes.


****Syntax:****


template &lt;typename T&gt; constexpr T pi = T(3.14159);


In the above statement, pi is the template variable. We use constexpr with the template variable because it ensures that the variable is a constant expression and is evaluated at compile time rather than at runtime.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T&gt; constexpr T pi = T(3.14159);

int main(){
    cout &lt;&lt; &quot;Pi as float: &quot; &lt;&lt; pi&lt;float&gt; &lt;&lt; endl;
    cout &lt;&lt; &quot;Pi as double: &quot; &lt;&lt; pi&lt;double&gt;;
    return 0;
}

**Output**Pi as float: 3.14159
Pi as double: 3.14159

****Explanation:****

- "template &lt;typename T&gt; constexpr T pi" defines a variable template for different data types.
- When you use "pi&lt;float&gt;" or "pi&lt;double&gt;", the compiler creates a version of pi for that type.
- "constexpr" ensures the value is known at compile time for better optimization.
- The program prints pi as a float and a double using the same template.
## Default Template Arguments


Like normal parameters, we can also specify default type arguments to templates. 

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T1, typename T2 = double, typename T3 = string&gt; class Geek{
  public:
    T1 x;
    T2 y;
    T3 z;
    
    Geek(T1 val1, T2 val2, T3 val3) : x(val1), y(val2), z(val3){
    }

    void getValues(){
        cout &lt;&lt; x &lt;&lt; &quot; &quot; &lt;&lt; y &lt;&lt; &quot; &quot; &lt;&lt; z;
    }
};

int main(){

    Geek&lt;int, float, string&gt; intFloatStringGeek(10, 5.67f, &quot;Hello&quot;);
    Geek&lt;char&gt; charDoubleStringGeek(&#39;A&#39;, 3.14, &quot;World&quot;);

    intFloatStringGeek.getValues();
    cout &lt;&lt; endl;
    charDoubleStringGeek.getValues();
    return 0;
}

**Output**10 5.67 Hello
A 3.14 World

****Explanation: ****In this code, when all template types are given, the class uses those exact types, but when only the first type is provided, the remaining template parameters automatically use their default types (double and string).

## ****T****emplate Non-Type Arguments


Templates can take non-type parameters (constant values, not types). These are used to fix values like size, max, or min for a template. Non-type parameters must be compile-time constants because the compiler generates the template code using those values at compile time.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;class T, int INIT&gt;int arrMin(T arr[], int n){
    int m = INIT;
    for (int i = 0; i &lt; n; i++)
        if (arr[i] &lt; m)
            m = arr[i];
    return m;
}

int main(){

    int arr1[] = {10, 20, 15, 12};
    int n1 = sizeof(arr1) / sizeof(arr1[0]);
    char arr2[] = {1, 2, 3};
    int n2 = sizeof(arr2) / sizeof(arr2[0]);
    cout &lt;&lt; arrMin&lt;int, 10000&gt;(arr1, n1) &lt;&lt; endl;
    cout &lt;&lt; arrMin&lt;char, 256&gt;(arr2, n2);

    return 0;
}

**Output**10
1
## Template Argument Deduction


Template argument deduction automatically deduces the data type of the argument passed to the templates. This allows us to instantiate the template without explicitly specifying the data type.


****Note: ****It is important to note that the template argument deduction for classes is only available since C++17, so if we try to use the auto template argument deduction for a class in previous version, it will throw an error.


The below example demonstrates how the STL max() method deduces the data type without being explicitly specified.

            C++

    #include &lt;bits/stdc++.h&gt;
using namespace std;

int main()
{
    cout &lt;&lt; max(3, 4);
    return 0;
}

**Output**4

****Note:**** The above program will fail compilation in C++14 and below compiler since class template arguments deduction was added in C++17.

### 1. Function Template Arguments Deduction


Function template argument deduction has been part of C++ since the C++98 standard. We can skip declaring the type of arguments we want to pass to the function template and the compiler will automatically deduce the type using the arguments we passed in the function call.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename t&gt; t multiply(t first, t second){
    return first * second;
}

int main(){
    cout &lt;&lt; multiply(3, 4);
    return 0;
}

**Output**12

****Note:**** For the function templates which is having the same type for the arguments like template&lt;typename t&gt; void function(t a1, t a2){}, we cannot pass arguments of different types.

### 2. Class Template Arguments Deduction (C++17 Onwards)


The class template argument deduction was added in C++17 and has since been part of the language. It allows us to create the class template instances without explicitly definition the types just like function templates.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;typename T&gt; class Geek{
  public:
    T x;
    T y;
    Geek(T val1, T val2) : x(val1), y(val2){}
    void getValues(){
        cout &lt;&lt; x &lt;&lt; &quot; &quot; &lt;&lt; y;
    }
};

int main(){
    Geek intGeek(10, 20);
    Geek doubleGeek(3.14, 6.28);
    
    intGeek.getValues();
    cout &lt;&lt; endl;
    doubleGeek.getValues();
    return 0;
}

**Output**10 20
3.14 6.28
## Template Metaprogramming


In C++, [****template metaprogramming****](https://www.geeksforgeeks.org/cpp/template-metaprogramming-in-c/) refers to template perform computation at the compile time rather than runtime. To perform computation at compile time, template metaprogramming involves recursive template structures where templates call other templates during compilation.

            C++

    #include &lt;iostream&gt;
using namespace std;

template &lt;int N&gt; struct Factorial{
    static const int value = N * Factorial&lt;N - 1&gt;::value;
};

template &lt;&gt; struct Factorial&lt;0&gt;{
    static const int value = 1;
};

int main(){
    cout &lt;&lt; &quot;Factorial of 5 is: &quot; &lt;&lt; Factorial&lt;5&gt;::value;
    return 0;
}

[Try It Yourself![redirect icon](https://media.geeksforgeeks.org/auth-dashboard-uploads/Group-arrow.svg)](https://www.geeksforgeeks.org/problems/c-template/1)**Output**Factorial of 5 is: 120

****Explanation: ****

- "template &lt;int N&gt;" defines a template that computes factorial recursively at compile time.
- "Factorial&lt;N&gt;::value" multiplies N with "Factorial&lt;N-1&gt;::value".
- The specialization "Factorial&lt;0&gt;" stops the recursion and returns 1.
- "Factorial&lt;5&gt;::value" is calculated by the compiler and printed at runtime.CommentArticle Tags:Article Tags:[C++](https://www.geeksforgeeks.org/category/programming-language/cpp/)[cpp-template](https://www.geeksforgeeks.org/tag/cpp-template/)[![GeeksforGeeks](https://media.geeksforgeeks.org/auth-dashboard-uploads/gfgFooterLogo.png)](https://www.geeksforgeeks.org/)![location](https://media.geeksforgeeks.org/img-practice/Location-1685004904.svg)Corporate &amp; Communications Address:A-143, 7th Floor, Sovereign Corporate Tower, Sector- 136, Noida, Uttar Pradesh (201305)![location](https://media.geeksforgeeks.org/img-practice/Location-1685004904.svg)Registered Address:K 061, Tower K, Gulshan Vivante Apartment, Sector 137, Noida, Gautam Buddh Nagar, Uttar Pradesh, 201305[](https://in.linkedin.com/company/geeksforgeeks)[](https://www.instagram.com/geeks_for_geeks/)[](https://twitter.com/geeksforgeeks)[](https://www.facebook.com/geeksforgeeks.org/)[](https://www.youtube.com/geeksforgeeksvideos)[![GFG App on Play Store](https://media.geeksforgeeks.org/auth-dashboard-uploads/googleplay-%281%29.png)](https://geeksforgeeksapp.page.link/gfg-app)[![GFG App on App Store](https://media.geeksforgeeks.org/auth-dashboard-uploads/appstore-%281%29.png)](https://geeksforgeeksapp.page.link/gfg-app)
