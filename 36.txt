# C++ STL Algorithm Library
Last Updated : 27 May, 2026
- 
- 
- 

Algorithms are ready-made functions that help you perform common operations like searching, sorting, counting, and comparing on containers (like arrays, vectors, sets, etc.). These algorithms are defined in the &lt;algorithm&gt; and &lt;numeric&gt; header files.

## Type of Algorithms


We can divide the algorithms into following parts:

### 1. Searching Algorithms


Searching algorithms are methods used to find a specific element or information in a data structure like an array, vector, or list.They help locate an element efficiently without manually checking each item.


Some of the most frequently used searching algorithms are:

- [find() ](https://www.geeksforgeeks.org/cpp/std-find-in-cpp/): Searches for an element and returns its iterator if present.
- [find_if()](https://www.geeksforgeeks.org/cpp/stdfind_if-stdfind_if_not-in-c/) : Finds the first element satisfying a given condition.
- [binary_search()](https://www.geeksforgeeks.org/cpp/cpp-binary-search/) : Checks if an element exists in a sorted container.
- [lower_bound()](https://www.geeksforgeeks.org/cpp/lower_bound-in-cpp/) : Returns an iterator to the first element not less than a given value.
- [upper_bound()](https://www.geeksforgeeks.org/cpp/upper_bound-in-cpp/) : Returns an iterator to the first element greater than a given value.
- [find_end()](https://www.geeksforgeeks.org/cpp/stdfind_end-in-cpp/) : Finds the last occurrences of a subsequence in a range.
### 2. Sorting and Rearranging Algorithms


These change the order or position of elements.

- [sort()](https://www.geeksforgeeks.org/cpp/sort-c-stl/) : Arranges elements in a given range into ascending order by default.
- [stable_sort()](https://www.geeksforgeeks.org/cpp/stable_sort-c-stl/) : Sorts elements while preserving the relative order of equal elements.
- [partial_sort()](https://www.geeksforgeeks.org/cpp/stdpartial_sort-in-cpp/) : Sorts only the first N elements in order, leaving the rest unsorted.
- [nth_element() ](https://www.geeksforgeeks.org/cpp/stdnth_element-in-cpp/): Rearranges elements so the nth position has the correct element as in sorted order, with smaller ones before it and larger ones after it (but unordered).
- [is_sorted()](https://www.geeksforgeeks.org/cpp/stdis_sorted-in-cpp/) : Checks if the given range is already sorted in ascending order (or by custom comparator).
- [is_sorted_until()](https://www.geeksforgeeks.org/cpp/stdis_sorted_until-in-cpp/) : Returns an iterator to the first element where the sorted order breaks.
### 3. Manipulation Algorithms


These change or update values in the container without necessarily sorting or searching them.

- [copy()](https://www.geeksforgeeks.org/cpp/different-methods-copy-c-stl-stdcopy-copy_n-copy_if-copy_backward/) : Copies element from one range into another range, preserving their order.
- [copy_if()](https://www.geeksforgeeks.org/cpp/different-methods-copy-c-stl-stdcopy-copy_n-copy_if-copy_backward/) : Copies only the elements that satisfy a given condition to another range.
- [copy_n()](https://www.geeksforgeeks.org/cpp/different-methods-copy-c-stl-stdcopy-copy_n-copy_if-copy_backward/) : Copies exactly n elements from a source range to a destination range.
- [copy_backward()](https://www.geeksforgeeks.org/cpp/different-methods-copy-c-stl-stdcopy-copy_n-copy_if-copy_backward/) : Copies elements from a source range to a destination range in reverse order, starting from the end.
- [move()](https://www.geeksforgeeks.org/cpp/stdmove-in-c/) : Transfers elements from a source range to a destination range, leaving the source elements in a valid but unspecified state.
- [swap() ](https://www.geeksforgeeks.org/cpp/swap-in-cpp/): Exchanges the values of two elements.
- [replace()](https://www.geeksforgeeks.org/cpp/stdreplace-stdreplace_if-c/) : Replaces all occurrences of a specific value in a range with a new value.
- [replace_if()](https://www.geeksforgeeks.org/cpp/stdreplace-stdreplace_if-c/) : Replaces all elements that satisfy a given condition with a new value.
- [remove()](https://www.geeksforgeeks.org/cpp/std-remove-algorithm-in-cpp/) : moves all elements not equal to a given value to the front of the range and returns an iterator to the new logical end (does not actually reduce container size).
- [fill()](https://www.geeksforgeeks.org/cpp/fill-in-cpp-stl/) : Assigns a specified value to every element in a given range.
- [transform()](https://www.geeksforgeeks.org/cpp/transform-c-stl-perform-operation-elements/) : Applies a function to each element in a range and stores the result in another range.
- [generate()](https://www.geeksforgeeks.org/cpp/stdgenerate-in-c/) : Assigns values to a range by repeatedly calling a given function or generator.
- [shuffle()](https://www.geeksforgeeks.org/cpp/shuffle-an-array-using-stl-in-c/) : Randomly rearranges the elements in a given range.
### 4. Counting &amp; Comparing Algorithms


These check or count elements based on conditions.

- [count()](https://www.geeksforgeeks.org/cpp/std-count-cpp-stl/) : Returns the number of elements in a range that are equal to a specified value.
- [count_if()](https://www.geeksforgeeks.org/cpp/count_if-in-c/) : Returns the number of elements in a range that satisfy a given condition.
- [equal()](https://www.geeksforgeeks.org/cpp/stdequal-in-cpp/) : Checks if two ranges have the same elements in the same order.
- [mismatch()](https://www.geeksforgeeks.org/cpp/stdmismatch-examples-c/) : Finds the first position where two ranges differ and returns iterators to the mismatched elements.
- [lexicographical_compare()](https://www.geeksforgeeks.org/cpp/lexicographical_compare-in-cpp-stl/) : Checks if one range is lexicographically less than another (like dictionary order).
- [is_permutation()](https://www.geeksforgeeks.org/cpp/stdis_permutation-c-stl/) : Checks if one range is a permutation of another, i.e., contains the same elements in any order.
### 5. &lt;numeric&gt; Functions


Include common functions like:

- [accumulate()](https://www.geeksforgeeks.org/cpp/accumulate-and-partial_sum-in-c-stl-numeric-header/) → sum of elements 
- [iota() ](https://www.geeksforgeeks.org/cpp/std-iota-in-cpp/)→ fills range with sequential values 
- [partial_sum()](https://www.geeksforgeeks.org/cpp/accumulate-and-partial_sum-in-c-stl-numeric-header/) → cumulative sum
